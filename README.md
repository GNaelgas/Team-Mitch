# Team Mitch · Virtual Hire - Sharepoint and Resources

Internal reference site for the API VH Collections team.

## Structure
- index.html      – the whole site (Home, Call Routing, Billing & Payments, Email Templates, Announcements, Training & Resources)
- assets/logo.png – banner logo
- files/          – downloadable documents and installers

## Publish on GitHub Pages
1. Upload the contents of this folder (not the folder itself) to the root of the repository.
2. Settings → Pages → Deploy from a branch → main / root.

Note: GitHub rejects single files over 100 MB, and a Pages site is publicly reachable by anyone with the link unless your organization uses GitHub Enterprise access control.
